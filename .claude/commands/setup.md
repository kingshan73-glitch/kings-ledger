CLAUDE.md 의 "🚀 초기 설정 도우미" 절차를 그대로 따라, 사용자를 위해 초기 설정을 한 단계씩 진행해줘.

- 한 번에 한 단계씩 진행하고, 각 단계 결과를 확인한 뒤 다음으로 넘어간다.
- `supabase login` · `gh auth login` · `vercel login` 같은 브라우저 인증은 `!` 로 돌리지 말고,
  사용자가 **새 터미널에서 직접** 실행하도록 안내한다. 그 밖의 비대화형 명령은 네가 직접 실행한다.
- DB 비밀번호는 네가 생성해 `.env.local` 에 저장하고, Supabase 키는 CLI 로 조회해 `.env.local` 에 적는다.
  비밀값을 채팅에 다시 출력하지 않는다.
- `npm run setup:admin` 뒤에 `npm run seed:demo` 로 가상 가족(김하늘·이바다)의 더미 데이터를 넣을지 물어보고,
  원하면 네가 실행한다.
- Supabase 무료 플랜은 조직당 활성 프로젝트 2개다. 윤비서 프로젝트가 이미 있으면 이번이 두 번째임을 알려준다.
- 에러가 나면 메시지를 읽고 원인·해결책을 쉬운 한국어로 설명한 뒤 재시도한다.

지금 0단계(사전 점검: git/node/npm/gh/supabase/vercel 버전 확인)부터 시작해줘.
